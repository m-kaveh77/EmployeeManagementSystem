# 👨‍💼 Employee Management System (WPF)

A powerful desktop application built with **Windows Presentation Foundation (WPF)** in C# to manage employee data. This system offers a modern user interface, smooth user experience, and full management capabilities for HR-related tasks.

---

## 🎯 Project Purpose

The purpose of this project is to provide a complete desktop-based solution for managing employee records, including registration, editing, deletion, search, and secure access. It is designed with scalability and user-friendliness in mind and is ideal for small to mid-sized organizations.

---

## ✨ Key Features

- 🔐 **Secure Login**  
  - Authentication via username and password  
  - Passwords are encrypted for added security

- 🗂️ **Basic Data Management**  
  - Manage essential supporting data such as education levels and job positions

- 📋 **Employee Record Management**  
  - View a list of all employees with key details  
  - Add new employees  
  - Edit or delete existing employee records  

- 🖼️ **Image Handling**  
  - Upload and display employee photos during registration/editing

- 🛢️ **Database Integration**  
  - All data is stored in **SQL Server 2022**  
  - CRUD operations are handled efficiently with secure access to the database
